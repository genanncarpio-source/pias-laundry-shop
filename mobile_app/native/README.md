# Pia's Laundry Shop Customer App

This is the Android/iOS Flutter project for the customer app. The Dart source is
kept in sync with `../lib/main.dart`. See `../README.md` for setup and APK build
instructions.

The Android package id is `com.piaslaundry.customer`. On first sign-in, use the
shop API address. For a physical phone, enter the computer's LAN IP and make
sure Apache is allowed through Windows Firewall. Use HTTPS outside local testing.
